# ps3mio - التصميم

## القرار
تطبيق Kotlin حُذف: لا يعمل على PS3 ولا علاقة له بمشغلها. المشروع الآن مساران لنفس الشيفرة فقط:
**Engine Android** (للتجربة على الهاتف) و**Engine PS3**.

محرك Movian يبقى لما يصعب كتابته دون جهاز: فك H.264 بعتاد PS3 (cellVdec)، الصوت، التورنت، TLS، الشبكة.
كل ما يراه المستخدم هو Stremio:

| الطبقة | المصدر |
|---|---|
| الصفحة الرئيسية والتنقل (Board / Discover / Library / Search / Addons / Settings) | سكن `engine/skin` فوق GLW |
| الإعدادات | صفحة Settings داخل منطق Stremio (حساب، مشغل، بث، لغة، متقدم) |
| API وaddons والترجمات | `engine/plugin` (مدمج، لا يحتاج تثبيت) |
| المشغل | مشغل Movian + شاشة تحميل بشعار العمل + خطوات التقديم والاستئناف من إعدادات Stremio |

## ما أُزيل من Movian
الصفحة الرئيسية (NAV_HOME = Stremio)، فحوص التحديث والإحصاءات والأخبار، وأي وصول لقوائم Movian من واجهتنا.

## ما لم يُنجز بعد
- قائمة المشغل (OSD) ما زالت قائمة Movian بألوان ps3mio؛ إعادة تصميمها لتطابق Stremio هي الخطوة التالية بعد تجربة السكن.
- إعدادات الترجمة (الحجم والألوان) تعتمد على إعدادات Movian الداخلية داخل المشغل ولم تُربط بصفحة Stremio.
- لم يُبنَ شيء على جهاز حقيقي؛ ملفات GLW لا تُفحص إلا عند التشغيل، فتوقع تعديلات من أول تجربة.
